# HumanOS

> An open-source computational framework for modeling and comparing human learning strategies under explicit assumptions.

## Mission

HumanOS aims to transform discussions about learning, habits, and decision-making into transparent, reproducible computational experiments.

Instead of asking:

> "What is the best strategy?"

HumanOS asks:

> "Under these assumptions, which strategies perform better?"

## Philosophy

- Evidence over opinion.
- Simple externally, rigorous internally.
- Reproducible experiments.
- Modular architecture.
- Open research.
